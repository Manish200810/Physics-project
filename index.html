02

Shadow Method

Our first approach: instead of touching the glass slab with a ruler, let light do the measuring.

Physics Principle

Light travels approximately in straight lines in a uniform medium. When a light source illuminates the glass slab, the slab produces a projection or shadow. By using a known reference length and the geometry of the light rays, similar triangles can be used to estimate unknown dimensions.

Apparatus

  • Rectangular glass slab
  • Light source
  • Screen or flat surface
  • Reference object
  • Metre scale
  • Stand/support

Setup

Place the glass slab between the light source and the screen. Keep the reference object in the same plane whenever possible so that the projected dimensions can be compared.

Important idea

The shadow is a geometrical projection. The ratio between projected lengths can be related to the ratio between actual lengths.

Procedure

  1. Place the glass slab in a fixed position.
  2. Illuminate it using a suitable light source.
  3. Obtain a clear projection on the screen.
  4. Place a reference object of known dimension in the setup.
  5. Measure the projected reference and slab dimensions.
  6. Use the geometric ratio to calculate the required dimensions.
  7. Repeat for length, breadth and thickness.

Length

Measure the length of the slab's shadow and compare it with the shadow of a reference object whose actual length is known.

Breadth

Use the corresponding breadth of the projected slab and the same calibration relationship.

Thickness

Orient the slab so that its thickness produces a measurable projection, then compare that projected thickness with the reference.

dimension ratio ≈ projected slab dimension / projected reference dimension

Unknown dimension ≈ known reference dimension × (projected slab dimension / projected reference dimension)

03

Parallax Method

Next, we changed the viewpoint. The slab stayed where it was; the apparent position changed.

Physics Principle

Parallax is the apparent displacement of an object when viewed from different positions. By measuring the displacement of the slab relative to a known reference and knowing the geometry of the setup, its dimensions can be estimated indirectly.

Apparatus

  • Glass slab
  • Reference object or scale
  • Two observation positions
  • Camera/eye
  • Support and measuring surface

Setup

Place the slab and reference in a fixed arrangement. Observe from two different positions while keeping the slab stationary.

Key concept

A larger apparent displacement generally indicates a different geometrical relationship between object distance and viewpoint shift.

Procedure

  1. Fix the glass slab and reference object.
  2. Observe the setup from the first position.
  3. Mark the apparent position.
  4. Move sideways by a known baseline.
  5. Observe and mark the second apparent position.
  6. Measure the resulting displacement.
  7. Use the appropriate geometrical relation.
  8. Repeat the setup for the three dimensions.

Length

Use parallax between the relevant edges of the slab and a reference to establish its longitudinal dimension.

Breadth

Change the viewing geometry so the lateral edges produce a measurable parallax displacement.

Thickness

Use the apparent displacement of front and rear surfaces or edges to estimate the thickness through the chosen geometry.

Parallax angle θ ≈ displacement / distance

The final dimensional equation depends on the exact experimental geometry.

04

Photography / Pixel Method

Then we realised a photograph is basically a grid of measurable pixels. So why not use the image itself as a measuring instrument?

Physics Principle

A digital photograph represents distances using pixels. If an object of known physical size is present in the same image plane, its pixel size can be used as a calibration scale.

Scale = Actual reference size / Reference size in pixels

Slab dimension = Slab dimension in pixels × Scale

Apparatus

  • Glass slab
  • Camera/phone
  • Reference object
  • Image measurement application
  • Stable setup

Procedure

  1. Place a reference object beside the slab.
  2. Take a photograph as straight-on as possible.
  3. Measure the reference in pixels.
  4. Measure the slab dimension in pixels.
  5. Calculate the pixel-to-length scale.
  6. Convert all three dimensions.

Why it works

The reference object provides the conversion between image coordinates and physical distance.

Length

Measure the slab's length in pixels and multiply by the calibrated scale.

Breadth

Measure the breadth in pixels using the same image calibration.

Thickness

Take a suitable side-view photograph and calibrate the thickness in pixels.

05

Optical / Refraction Method

Finally, we turned to one of the most interesting properties of a glass slab: it changes the path of light.

Physics Principle

When light travels from one transparent medium to another, its direction changes because its speed changes. This phenomenon is refraction. The relationship between the angles is described by Snell's law.

n₁ sin i = n₂ sin r

For a plane-parallel slab:
d = t · sin(i − r) / cos r

where d is lateral displacement and t is slab thickness.

Apparatus

  • Glass slab
  • Ray box / laser or suitable light source
  • Paper
  • Pins/markers
  • Protractor
  • Scale

Procedure

  1. Place the slab on paper.
  2. Trace its outline.
  3. Send a ray through the slab.
  4. Mark incident and emergent rays.
  5. Measure angles and lateral displacement.
  6. Use refraction equations and geometry.

Key idea

The optical path provides geometric information about the slab and its surfaces.

Length

Use the traced outline and optical geometry to establish the longitudinal dimension of the slab.

Breadth

Use the corresponding transverse boundaries in the traced optical setup.

Thickness

Use lateral displacement and the refractive geometry to determine thickness where the setup permits it.

07 · The plot twist

We also tried free fall.

Because apparently four methods weren't enough. We attempted to use a falling object and timing measurements as another indirect approach.

And… it didn't really work. 😭

  • The ball has a finite size, so its exact release point is uncertain.
  • It is difficult to release the ball from exactly the same position every time.
  • Timing a short fall introduces significant uncertainty.
  • Small alignment errors affect the measured distance.
  • Human reaction time can dominate the measurement uncertainty.
