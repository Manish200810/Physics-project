A physics experiment, told as a journey

One glass slab.
Four ways to measure it.

We wanted to find the length, breadth and width/thickness of a rectangular glass slab using indirect methods. So instead of reaching for a ruler first, we tried to make light, geometry, viewpoint, pixels and refraction do the measuring.

Start the experiment ↓ Jump to the methods
01 · The question

We didn't just want a number.

The interesting question was: can a dimension be hidden inside another observable quantity? A shadow has geometry. A viewpoint has parallax. A photograph has pixels. A glass slab bends light. So we turned the measurement into an investigation.

01 — Start with the slab

We had a simple rectangular glass slab and three quantities we needed to determine: length, breadth and thickness.

02 — First idea: use its shadow

If light travels in straight lines, perhaps the shadow can preserve enough geometry to reveal the dimensions.

03 — Second idea: change the viewpoint

If an object's apparent position changes when the observer moves, that displacement can become useful. That led us to parallax.

04 — Third idea: turn the slab into pixels

A photograph is made of pixels. If we can establish a known scale, pixels can become physical dimensions.

05 — Fourth idea: make light reveal itself

Glass refracts light. That meant the path of a ray itself could provide information about the slab.

06 — And then there was one more attempt…

We tried free fall. We'll save that story until the end.

02 · Method one

🌑 Shadow Method

Our first attempt was based on one of the simplest ideas in optics: light travels in straight lines.

01
Physics principle — rectilinear propagation of light: Light travels approximately in straight lines in a uniform medium. When a slab blocks light from a controlled source, its shadow reproduces geometric information about the object's boundaries. By using a known reference geometry and proportional relationships, the shadow can be used for indirect measurement.

Apparatus

Rectangular glass slab · point/controlled light source · screen or suitable surface · stand/holder · metre scale or known reference.

What we observe

Instead of touching the slab directly with the scale, we observe the geometry produced by the light and shadow.

Procedure

  1. Place the glass slab in a stable position.
  2. Arrange the light source so that a clear shadow is produced.
  3. Mark the relevant shadow boundaries.
  4. Measure the known distances and shadow dimensions.
  5. Use the geometric proportionality of the setup.
  6. Repeat the observation and compare the results.
Length Use the shadow boundary corresponding to the slab's longer dimension and the known geometry of the light-source setup.
Breadth Use the perpendicular shadow dimension with the same geometric relationship.
Width / Thickness Use the shadow displacement or projected edge associated with the slab's thickness, depending on the actual arrangement.
Geometrically: dimension ratio = corresponding shadow/reference ratio The exact working equation should be filled using the actual distances and geometry used during the experiment.

03 · Method two

👁️ Parallax Method

This time we changed something deliberately: our point of view.

02
Physics principle — parallax: Parallax is the apparent displacement of an object when viewed from different positions. By controlling the observer position and comparing apparent alignment or displacement, geometric information about the object's dimensions can be obtained.

Apparatus

Glass slab · reference markers/pins · scale · stable setup · controlled observation positions.

Key idea

The object does not physically move. Its apparent position changes because our viewpoint changes.

Procedure

  1. Place the slab and reference markers in a fixed setup.
  2. Observe from one controlled position.
  3. Move the observer to another position.
  4. Record the apparent displacement or alignment change.
  5. Use the geometry of the setup to infer the required dimension.
  6. Repeat the observation for consistency.
Length Measure the apparent displacement associated with the two ends of the slab along its longer direction.
Breadth Repeat the same geometric idea perpendicular to the length direction.
Width / Thickness Use the parallax between appropriate front/rear or upper/lower reference edges to infer the slab thickness.
Parallax geometry: apparent displacement → known viewing geometry → physical dimension The final equation depends on the exact observer distances, reference points and geometry used in the actual setup.

04 · Method three

📷 Photography / Pixel Method

Now we stopped measuring the physical object directly. Instead, we measured its image.

03
Physics principle — pixel calibration: A digital photograph represents an object using pixels. If a known physical reference length is visible in the same image, the number of pixels corresponding to that reference can establish a scale factor. That scale can then be applied to the measured pixel dimensions of the glass slab.

Apparatus

Glass slab · camera/phone · known reference scale/object · stable surface · suitable lighting.

Basic relationship

scale = actual reference size ÷ reference pixels

dimension = slab pixels × scale

Procedure

  1. Place a known reference beside the glass slab.
  2. Take a photograph with the slab and reference in the same measurement plane.
  3. Determine the reference length in pixels.
  4. Determine the corresponding slab dimension in pixels.
  5. Convert the pixel measurement using the scale factor.
  6. Repeat for length, breadth and thickness where the geometry allows.
Length Measure the pixel distance between the two ends of the slab and convert it using the calibrated scale.
Breadth Measure the perpendicular pixel distance between the slab's side edges.
Width / Thickness Measure the visible thickness in the photograph, provided the camera angle and reference geometry allow that dimension to be resolved reliably.
Scale = Known physical dimension / Corresponding pixel dimension

Measured slab dimension = Slab pixel dimension × Scale Perspective, camera tilt, lens distortion and uncertain edge pixels can affect the accuracy.

05 · Method four

🔬 Optical / Refraction Method

The fourth route uses one of the most recognisable behaviours of a glass slab: it changes the path of light.

04
Physics principle — refraction and Snell's law: When light passes between media of different refractive indices, its direction changes. For a plane-parallel glass slab, the emergent ray is parallel to the incident ray but is laterally displaced. That measurable optical behaviour can be related to the slab geometry in a suitable experimental arrangement.

Apparatus

Glass slab · ray box/laser or controlled light source · screen/paper · pins/markers as required · protractor · scale.

Core law

n₁ sin i = n₂ sin r

Procedure

  1. Set the slab and light path in the chosen geometry.
  2. Mark the incident and emergent directions carefully.
  3. Measure the relevant angles or displacement.
  4. Use the optical relation appropriate to the arrangement.
  5. Repeat with controlled geometry.
  6. Analyse the configuration for length, breadth and thickness.
Length Use an optical geometry aligned with the long dimension and the measured displacement or angles.
Breadth Repeat the optical construction in the perpendicular direction to determine the second planar dimension.
Width / Thickness Use lateral displacement and refraction geometry associated with the slab thickness.
For a plane-parallel slab: d = t · sin(i − r) / cos r Here t represents slab thickness. The exact working equation used in the final project must match the actual experimental ray geometry.

07 · The plot twist

And then… we tried free fall.

Not every clever-looking method survives contact with an actual experiment.

⚠️ Failed attempt · revealed at the end

What we tried

We explored a free-fall approach where a falling object and timing information were supposed to provide the basis for an indirect measurement. In theory, the equations are clean. In practice, our setup was not.

Why it failed

  • Finite size of the ball: the release and impact positions were not ideal point events.
  • Release uncertainty: even a small initial push or height difference changes the result.
  • Timing error: human/manual timing is difficult over a short fall.
  • Alignment: the setup has to be geometrically consistent for the model to work.
  • Measurement uncertainty: small errors can become large after calculation.

What we learned

Failure was not useless. It showed us that a method can be mathematically correct but experimentally weak. A good experiment is not just an equation — it is an equation plus a setup capable of supporting the assumptions.

Experimental lesson: If the uncertainty in the setup is comparable to the quantity being measured, the method needs improvement before the calculation means much.
